# 🗺️ Python Adventure Game

## 📌 About the Project
Python Adventure Game is a simple text-based game built using Python. In this game, players make decisions at different stages of an adventure. Each choice leads to a different outcome, and the goal is to make the right decisions to win the game.

This project is perfect for beginners who want to practice Python fundamentals through a fun, interactive program.

## 🎮 Features
- Personalized welcome message using the player's name.
- Interactive storyline with multiple choices.
- Different paths based on user decisions.
- Multiple winning and losing outcomes.
- Input validation for incorrect choices.
- Beginner-friendly code using conditional statements.

## 🛠️ Technologies Used
- **Language:** Python
- **Concepts:** `input()`, `print()`, `if-elif-else`, nested conditional statements, string methods, and user interaction.

## 🚀 How to Run the Project

### 1. Install Python
Download and install Python from the official website if it is not already installed.

https://www.python.org/downloads/

### 2. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 3. Open the Project Folder
```bash
cd python-adventure-game
```

### 4. Run the Game
Save the Python code in a file named `adventure.py` and run:

```bash
python adventure.py
```

## 🕹️ How to Play
1. Enter your name to begin the adventure.
2. Choose **left** or **right** at the dirt road.
3. Follow the instructions for each situation.
4. Enter your choices to determine your fate.
5. Try to find the winning path!

### 🏆 Winning Path
Choose the following options in order:

**Right → Cross → Yes**

You will meet a stranger who gives you gold, and you win the game!
